# One-Way Платформы

Эта система позволяет:

- запрыгивать на платформу снизу вверх;
- стоять на ней сверху;
- проваливаться вниз по `вниз + прыжок`.

## Как добавить платформы в уровень

Рекомендуемый путь:

1. Открой prefab комнаты или сцену с комнатой.
2. Выдели `Grid` комнаты.
3. Создай новый tilemap:
   - `GameObject -> 2D Object -> Relic Keeper -> One-Way Platform Tilemap`
4. Появится объект `Platforms` как дочерний к `Grid`.
5. На нём уже будут настроены:
   - `Tilemap`
   - `TilemapRenderer`
   - `Rigidbody2D (Static)`
   - `TilemapCollider2D`
   - `CompositeCollider2D`
   - `PlatformEffector2D`
   - `OneWayPlatformTilemap`
6. Рисуй на этом tilemap только платформы, через которые можно:
   - запрыгнуть снизу,
   - стоять сверху,
   - провалиться вниз.

## Как это работает

- объект `Platforms` автоматически ставится на layer `OneWayPlatform`;
- `PlatformEffector2D` делает коллизию односторонней;
- игрок может временно игнорировать текущую платформу при `вниз + прыжок`.

## Как провалиться вниз

По умолчанию:

- нажми `вниз`;
- пока зажат `вниз`, нажми `прыжок`.

Игрок на короткое время отключает коллизию с платформой под ногами и падает сквозь неё.

## Что важно при проектировании уровней

- Рисуй one-way платформы только на отдельном tilemap `Platforms`.
- Не смешивай обычную землю и one-way платформы в одном tilemap.
- Обычная земля должна оставаться на `Ground`.
- One-way платформы должны лежать только на `OneWayPlatform`.

## Какой слой использовать

Система уже ожидает layer:

- `OneWayPlatform`

Он добавлен в проект и выставляется компонентом автоматически.

## Для врагов

Враги тоже видят `OneWayPlatform` как поверхность.

Это значит:

- они смогут стоять на таких платформах;
- ground-check и ledge-check у них учитывают этот слой.

Но враги пока не умеют специально проваливаться сквозь них вниз. Это поведение есть только у игрока.

## Если платформа не работает

Проверь по списку:

1. объект платформы создан именно через `One-Way Platform Tilemap`;
2. у объекта layer = `OneWayPlatform`;
3. на объекте есть `PlatformEffector2D`;
4. у игрока `PlayerMovement` видит слой `OneWayPlatform`;
5. платформа нарисована на tilemap `Platforms`, а не на обычном `Ground`.
