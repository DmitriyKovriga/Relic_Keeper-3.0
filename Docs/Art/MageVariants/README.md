# Mage base-sprite options

Nine separate PixelLab Pro edits of the mage's original resting sprite.
These are design candidates only; no candidate is assigned to the game.
The 28 x 28 reference was taken from `MageWalk-Sheet_0` and padded with two
transparent pixels on each side for the model's 32 x 32 minimum. No source
pixels were rescaled or painted.

`Comparison.png` shows options 01-09 at the same nearest-neighbor scale,
alongside the original and a native-size thumbnail for each candidate.
`Mage-01.png` through `Mage-09.png` are the original transparent AI outputs.

| Option | Direction |
| --- | --- |
| 01 | Classic: closest polish of the original |
| 02 | Scholar: open hood, collar and a small scroll case |
| 03 | Wanderer: worn travel cloak and practical cuffs |
| 04 | Battle mage: fitted cloth and light leather reinforcement |
| 05 | Mystic: subtle trim and a small collar clasp |
| 06 | Short mantle: lighter shoulder covering |
| 07 | Archivist: chest strap and a belt-mounted book pouch |
| 08 | Hood down: exposed blonde hair |
| 09 | Deep cowl: deeper hood shadow with a visible face |

`manifest.json` records job IDs, seeds and requested directions. The selected
candidate will need pixel-grid and equipment-grip alignment and matching
animations before integration. Preserve these original PNGs for future reuse.
