# Female mage: wizard robe and hat options

Nine separate PixelLab Pro reference edits using the user's supplied outfit
illustration. Only clothing cues are requested: pointed violet hats, layered
robes, charcoal inner cloth, restrained gold piping and diamond-shaped clasps.
The existing female mage's blonde hair, compact body proportions and grounded
pixel style are retained; hands remain free for runtime equipment.

The canvas is 32 x 40, with additional vertical room for the hat rather than
compressing the body. Variant 09 was selected and integrated into the Mage character.
All earlier sets remain preserved. `Mage-01.png` through `Mage-09.png` are the
unaltered transparent outputs. `OutfitReference.png` is the user-provided
reference illustration, not a game asset. `Previous.png` is the prior option 02.

`Comparison.png` displays the candidates at the same nearest-neighbor scale,
with a native-size thumbnail. Generation IDs, seeds and directions are in
`manifest.json`. No generated sprite pixels are manually painted or recolored.

Matching PixelLab run and airborne source frames are preserved in `SelectedAnimation/`. The original candidates remain unchanged. Integration details: `Docs/MageMovementRefresh.md`.
