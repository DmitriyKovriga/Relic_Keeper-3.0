# Warrior sprite variants

Nine separate PixelLab Pro reference edits of the existing Warrior portrait.
Each design keeps the compact native pixel scale, earthy palette, exposed head
and empty hands for runtime equipment. Outfit details vary from leather to light
mail and restrained metal armour. These are design options, pending selection.

`OriginalPortrait.png` is the existing 28x28 portrait frame.
`Current.png` is the current refined movement rest frame.
`Reference.png` pads the portrait to 32x32 with two transparent pixels per side;
no source pixels are rescaled or repainted. Generated `Warrior-01.png` through
`Warrior-09.png` are unaltered 32x32 transparent PixelLab outputs.

`Comparison.png` displays all options at the same nearest-neighbor scale, with
native-size thumbnails and the original for comparison. Seeds, job IDs and
outfit directions are recorded in `manifest.json`. The game assets remain unchanged.
