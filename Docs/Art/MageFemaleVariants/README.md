# Female mage sprite options

A second set of nine PixelLab Pro candidates, revised to read clearly as a
young adult female mage: softer facial shapes, visible blonde hair, narrower
shoulders and a more graceful cloth silhouette. The teal/violet/burgundy palette
and compact pixel style are retained. These are candidates only; the game is
unchanged and the previous set remains in `Docs/Art/MageVariants`.

All nine previous designs were edited together with the same instruction to
keep style and character identity consistent while preserving costume variation.
Generation: `e4409041-00e1-445c-b88f-8c3911546195`, seed `29114`.
The output frame indices 0-8 correspond to options 01-09.

`Comparison.png` shows all candidates at 5x nearest-neighbor scale and native
size, with the original mage above. `Mage-01.png` through `Mage-09.png` are
unaltered transparent 32 x 32 outputs. No generated pixels were manually painted
or recolored. Source job IDs and output indices are in `manifest.json`.
