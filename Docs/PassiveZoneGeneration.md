# Генерация зон пассивного дерева

## Использование

В редакторе дерева открыть «Зоны», пометить каркас, выбрать сторону и нажать
«Сгенерировать». «Ещё раз» выбирает новый seed. Поля и сохранённые настройки
прежнего инструмента совместимы.

- **Кластеров и ветвей** — точное количество связных сущностей, если не считать
  каркас. В простом режиме генератор сам подбирает смесь размеров.
- **Подробный режим** — точные квоты каждого типа. Они не заменяются другими
  типами ради более лёгкого размещения.
- **Лимит нодов** — верхняя граница, не требование заполнить всё. Входные ноды
  входят в лимит, каркас и декоративные центры орбит — нет. `0` снимает лимит.
- Две орбиты одного кластера считаются одной сущностью. Два входа в кластер также
  не добавляют сущность.
- Неудачный подбор сохраняет прежнюю зону целиком. Сообщение показывает лучший
  частичный подбор, но этот подбор не применяется.
- Если включена связь противоположных зон, успешная генерация копируется через
  существующий механизм синхронизации. Неудачная генерация его не запускает.

Закрепление отдельных частей и частичная перегенерация отложены. Ноды после
генерации не получают шаблонов, иконок или характеристик: инструмент меняет
геометрию, как и прежде. Ручные правки выбранной зоны заменяются только при
успешной генерации; действие поддерживает штатный Undo редактора.

## Каталог и источник

Источник геометрических референсов:
<https://www.pathofexile.com/passive-skill-tree> (выгрузка, полученная 2026-09-30).
Описание орбит: <https://github.com/grindinggear/skilltree-export/blob/master/README.md>.

Обработаны все 797 групп выгрузки. Из **341 подходящей группы** выделены
**349 связных фрагментов**. После удаления повторов с учётом поворота, отражения,
порядка нодов и общего масштаба получены **87 форм** по 3–12 нодов.

`Assets/Editor/PassiveTree/Zones/PassiveZoneMotifs.json` содержит локальный
каталог: орбиты, углы, рёбра, позиции входов и наград, ссылки на исходные группы.
Иконки, характеристики, расположение всего дерева и игровые механики PoE не
импортируются. Mastery исключены вместе с их специальными связями; независимые
компоненты одной исходной группы разделены. Ascendancy, служебные, blighted,
стартовые ноды, jewel sockets и keystones исключены.

В каталоге сохранены SHA-256 входной выгрузки и исходные названия для проверки
происхождения. Названия из референсов не присваиваются игровым нодам.
Обычная генерация работает без интернета.

Повторный импорт JSON официальной выгрузки или сохранённой HTML-страницы:

```powershell
python Tools/PassiveTree/import_poe_motifs.py path/to/data.json
```

Это явное обновление каталога. Оно может менять результаты старых seed.

## Вариации и композиция

Каждая форма адаптируется к проекту:

- общий плавный сдвиг углов на орбитах, без независимого шума позиций;
- небольшое изменение соотношения радиусов;
- выбор входного порта, поворот и отражение;
- размещение наград с проверкой стоимости и расстояний;
- при необходимости — короткий входной участок, включённый в бюджет;
- дополнительный вход только при сохранении стоимости всех наград;
- шесть семейств отдельных дуговых/волнистых/крючковых тупиков с изменяемой длиной.

Ноды на окружностях остаются `OnOrbit`. Длинная волна строится одной кубической
кривой: ноды распределяются по её длине, после чего кривая точно разрезается
на сегменты с согласованными касательными. Привязка к сетке применяется при
ручном перемещении, а генерация сохраняет точную геометрию кривых.

Поиск строит 40 кандидатов всей зоны. Формы растут от выбранных нодов каркаса
в непрерывно выбираемом направлении; фиксированных слотов нет. В простом режиме
поиск также меняет смесь размеров, сохраняя общее число сущностей. В подробном
режиме все квоты неизменны.

Оценка предпочитает разные семейства, распределение входов и наград, читаемые
промежутки, локально согласованные дуги и сбалансированное заполнение зоны.
Количество нодов не является оценкой красоты и не добивается искусственно.
Границы вычисляются по каркасу и выбранному клину; жёсткого радиуса 490 нет.
Внешние keystones не становятся новыми входами и не расширяют область генерации.

## Проверки

- До среднего нода требуется минимум 2 малых у малого кластера/тупика, 3 у
  среднего, 4 у большого/сложного. Проверяется минимальное количество **малых**
  по всем маршрутам от всех входов. Другие награды не заменяют малые ноды.
- Контроль расстояний учитывает размеры нодов; две средние награды разнесены
  минимум на 78 единиц.
- Проверяется попадание линий в посторонние ноды, пересечения, тесные параллельные
  линии, границы зоны, бюджет и целостность всего заказа.
- Геометрические проверки используют полилинии настоящих дуг и Bezier, включая
  подводящие рёбра. Внутри общего нода разрешён только непосредственный стык.
- После сборки на копии проверяется геометрия сериализуемого результата.
  Оригинальное дерево изменяется только после успешного подбора и проверки.
- При неизменном каркасе, соседях, каталоге и настройках seed воспроизводит
  геометрию. Это не гарантия сохранения наполнения нодов при перегенерации.

Автоматические проверки не заменяют визуальную оценку композиции. Разные
значения seed сохраняют намеренно разную плотность. Заведомо слишком плотный
заказ может завершиться отказом с сохранением прежней зоны.

## Проверка в Unity и галерея

```powershell
agents-unity-bridge refresh --timeout 60
agents-unity-bridge compile --timeout 60
agents-unity-bridge run-tests --mode EditMode --filter RelicKeeper.Tests.EditMode.PassiveZoneGeneratorTests --timeout 60
agents-unity-bridge run-tests --mode EditMode --filter RelicKeeper.Tests.EditMode.PassiveZoneCompositionTests --timeout 180
agents-unity-bridge get-console-logs --limit 20 --filter Error
```

Тесты композиции экспортируют реальные результаты с копий дерева в
`Library/PassiveZonePreviews`. Эти JSON не изменяют игровые ассеты.
Контактный лист строится из экспортированных координат и кривых:

```powershell
python Tools/PassiveTree/render_zone_samples.py path/to/generated-zones.png
```

Для рендера нужен Pillow. Контактный лист — схема геометрии, не скриншот GPU.

## Файлы реализации

- `PassiveZoneGenerator.cs`: точный заказ, поиск композиций, безопасное применение.
- `PassiveZoneDraft.cs`: адаптация форм, стоимость путей, плавные кривые, сериализация.
- `PassiveZoneGeometry.cs`: геометрия, границы и проверки столкновений.
- `PassiveZoneMotifLibrary.cs`, `PassiveZoneMotifs.json`: загрузка и данные каталога.
- `PassiveZoneMath.cs`: стоимость в малых нодах вместо числа любых промежуточных нодов.
- `PassiveZoneToolsPanel.cs`: ясные подписи лимитов и применение только при успехе.
- `PassiveZoneGeneratorTests.cs`, `PassiveZoneCompositionTests.cs`: регрессии и проверка серий seed.
- `Tools/PassiveTree/import_poe_motifs.py`, `render_zone_samples.py`: воспроизводимый сбор референсов и визуальная проверка.
