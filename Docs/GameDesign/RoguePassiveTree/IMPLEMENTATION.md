# Rogue tree v4 implementation

Implements the canonical plan from commit `5e033471`. The initial tree SHA-256 matched the handoff snapshot. Geometry, IDs, node types, clusters, orbits and Bezier curves are retained. Only reciprocal n30–n74 and n33–n73 connections are added.

`RelicKeeper.Editor.PassiveTree.RogueTreePlanBuilder.Apply` builds the 43 shared templates and assigns them to existing node IDs. It checks geometry/topology and stat enum identities before applying. The existing 24 transport references retain their shared asset. Start has no stat template. Unique modifiers are cleared to prevent duplicate grants.

Names use the existing `MenuLabels` keys (`passive.node.<template asset name>.name`), which already support tooltips and bilingual search. Stat descriptions remain generated by the existing localized stat formatter; no parallel manual formulas are introduced.

PixelLab generates one opaque action illustration per new template. The revised direction follows the Warrior tree's poses and effects: hooded figures dodging, striking, drawing bows, healing and channeling elemental/venom auras. Shields, heraldry and metal badges are replaced. Small/notable source sprites are 32px; keystones are 48px. Existing tree frames display them at 24/32/48 respectively. Point filtering, no mipmaps, no compression; no UI layout changes. PixelLab job provenance and per-icon visual subjects are recorded in `icon-jobs.json`. `RefreshIcons` imports only artwork without rewriting tree content or localization.

Art revision checks: all 43 replacements were reviewed together at twice the actual node display sizes; sparse Elemental Guard and Blade Master subjects were refined. Native dimensions and fully opaque alpha were checked on every PNG. Sprite `.meta` identities were retained. SHA-256 comparison confirms the tree and English/Russian localized content are unchanged by this artwork revision. The existing green hooded transport illustration is retained.

Verification targets: exact per-node plan effects and placement, shared-template counts, complete symmetric graph, bilingual names/icons, and the actual Dance of Blades scaling/removal path. Existing passive and resource-max regression suites remain applicable. Full combat balance across every build is a separate playtest task.

Results: all 134 plan-specific tests passed, plus 36 existing passive/resource regression cases. One existing global audit fails on the unchanged `IgniteMultAndDuration.asset` (IgniteChance uses PercentAdd); this asset is outside the Rogue plan and is unchanged from HEAD. All 43 generated PNGs passed dimensions/opaque-background checks and were reviewed in a contact sheet. An isolated runtime UI capture did not render successfully, so no full in-game visual verification is claimed. Geometry/curve preservation was also checked in the source diff; only template references and the four reciprocal leaf-link entries change in the tree asset.
