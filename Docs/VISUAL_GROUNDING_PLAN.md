# Visual Grounding Plan

## Что реализуем

- [ ] Контактная тень под игроком
- [ ] Контактная тень под обычными врагами
- [ ] Усиленная тень под крупными врагами
- [ ] Пыль при приземлении игрока
- [ ] Пыль при рывке игрока
- [ ] Пыль/импакт при тяжелых ударах и тяжелых шагах крупных врагов
- [ ] Простая система настройки grounding по prefab/сущности
- [ ] Правило сортировки и pixel-perfect для grounding FX

## Что нужно от тебя

### Обязательный минимум
- [ ] `Shadow_Small` — мягкая овальная тень для игрока и мелких мобов
- [ ] `Shadow_Medium` — тень для обычных гуманоидов
- [ ] `Shadow_Large` — тень для крупных врагов
- [ ] `Dust_Land_Small` — спрайты или спрайт-лист маленькой пыли при приземлении
- [ ] `Dust_Dash_Small` — пыль/сдвиг поверхности для dodge/рывка
- [ ] `Dust_Heavy_Impact` — более тяжелый импакт для knight и крупных врагов

### Желательно
- [ ] `Dust_Run_Small` — легкая пыль для быстрых шагов
- [ ] `Dust_Run_Heavy` — тяжелая пыль для крупных шагов
- [ ] `Ground_Scrape` — короткий след торможения/сдвига по полу

## Ориентировочные цвета

- [ ] `Shadow base` — RGB `38, 28, 36`
- [ ] `Shadow soft edge` — RGB `54, 40, 50`
- [ ] `Shadow heavy core` — RGB `28, 20, 26`
- [ ] `Dust base` — RGB `146, 118, 112`
- [ ] `Dust light` — RGB `182, 154, 144`
- [ ] `Dust dark` — RGB `108, 84, 82`
- [ ] `Heavy impact dust` — RGB `126, 100, 96`
- [ ] `Ground scrape dark` — RGB `88, 66, 68`

## Технические требования к ресурсам

- [ ] Прозрачный фон
- [ ] Pixel art без blur
- [ ] Один PPU-подход, как у остальной игры
- [ ] Тени без жесткого черного: лучше темно-коричневые/темно-серо-фиолетовые
- [ ] Пыль в 2-4 кадра минимум, heavy impact в 4-6 кадров

## Что я сделаю после получения ресурсов

- [ ] Соберу runtime grounding system
- [ ] Подключу ее к игроку
- [ ] Подключу базово ко всем текущим врагам
- [ ] Вынесу параметры размера/оффсета/тригеров в удобную настройку
- [ ] Проверю sorting, pixel-perfect и читаемость в бою
