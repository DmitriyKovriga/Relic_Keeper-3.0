# Движение персонажа

Референс — Brawlhalla: короткое наземное ускорение, низкий dash jump,
быстрое падение по команде и возможность связать движение с атакой.
Это адаптация к ARPG, а не копия покадровых чисел Brawlhalla.
Источники: [анонсы разработчиков о введении Dash](https://store.steampowered.com/news/posts/?appids=291550includes&enddate=1505340875)
и [Short Hop Accessibility](https://store.steampowered.com/news/posts/?appids=291550&enddate=1685541626&feed=steam_community_announcements).

## Управление

- Направление + Dodge (по умолчанию Shift / RB) на земле: короткий деш.
- Во время деша Jump: низкий прыжок с горизонтальной инерцией. Одновременное нажатие тоже поддерживается.
- Обратное направление: торможение и разворот, в том числе после деша и в воздухе.
- Вниз в воздухе: быстрое падение. Нажать можно заранее; минимальная фаза подъёма — 0,18 с для обычного прыжка и 0,04 с для dash jump. Отпускание вниз отменяет ожидание.
- Вниз + Jump на односторонней платформе: прежний проход сквозь платформу.
- Dodge без направления / в воздухе: прежнее защитное уклонение.

Наземный деш теперь **не даёт неуязвимости и не вызывает событие Dodged**.
Его короткий отдельный cooldown не сбрасывает cooldown защитного уклонения.
Это позволяет часто двигаться, не получая постоянную защиту. Пассивные эффекты
на Dodged продолжают относиться к защитному уклонению.
Число прыжков осталось прежним: один наземный и один воздушный.

## Настройки

Параметры PlayerMovement и PlayerAttackInput доступны в Inspector объекта Player.
Уже сохранённые значения сцены имеют приоритет над начальными значениями C#;
рабочий набор обновлён в Assets/Scenes/HubScene.unity.

| Параметр | Значение | Эффект |
|---|---:|---|
| Ground Acceleration / Deceleration | 90 / 55 | Быстрый старт, небольшое торможение по отпусканию |
| Air Acceleration / Deceleration | 65 / 16 | Управление с небольшой воздушной инерцией |
| Ground / Air Turn Acceleration | 140 / 100 | Отдельная сила разворота |
| Momentum Deceleration | 18 | Затухание избыточной скорости при удержании направления |
| Coyote Time | 0,10 с | Допуск прыжка после схода с края |
| Jump / Dodge Input Buffer | 0,12 с | Сохранение раннего нажатия до доступного действия |
| Ground Dash Time / Cooldown | 0,14 / 0,20 с | Продолжительность и частота наземного деша |
| Ground Dash Brake Delay | 0,04 с | Минимальная фаза перед отменой назад или атакой |
| Dash Jump Vertical Multiplier | 0,62 | Высота ниже обычного прыжка |
| Dash Jump Horizontal Speed | 12,5 | Минимальная начальная скорость dash jump |
| Fall Gravity Multiplier | 1,35 | Более плотная нисходящая часть прыжка |
| Fast Fall Gravity Multiplier | 2,05 | Ускоренное падение по вводу вниз |

Скорость обычного движения берётся из StatType.MoveSpeed, бонус прыжка — из
StatType.JumpForce. Деш сохраняет собственную настраиваемую дистанцию.
При удержании направления инерция плавно затухает; отпускание и обратный ввод
немедленно возвращают обычное торможение. Столкновение не восстанавливает
сохранённую скорость деша.

PlayerMovementVisual создаёт отдельный дочерний спрайт для деформации:
7,5% растяжения при прыжке и 5,5% сжатия при посадке, с быстрым возвратом.
Исходный SpriteRenderer остаётся источником анимации, цвета и материала;
физический Transform, коллайдер и точки крепления не деформируются.
Компонент добавляется при запуске; интенсивность можно проверить в Play Mode.

## Проверка

Tools → Relic Keeper → Run Movement Tests запускает регрессии в Unity Test Runner.
Результат сохраняется в Library/MovementTestResults.xml.

Проверено в Unity 6000.3.11f1: 17/17 EditMode-тестов прошли.
Дополнительно проведён игровой прогон HubScene с виртуальной клавиатурой
Unity Input System: бег, деш, разворот, остановка, обычный прыжок,
fast fall и одновременный dash jump. Запись — Library/MovementSmoke.csv.
В ней зарегистрированы скорость деша 15,714 ед./с, переход с отрицательной
на положительную скорость после обратного ввода и визуальный масштаб 1,075
по вертикали при прыжке. Временный генератор ввода убран из Assets.

При запуске сцены обнаружена отдельная ошибка GameSaveManager.LoadGame:
`Value cannot be null (key)`, после которой система запускает новую игру
с персонажем по умолчанию. Система сохранений в рамках движения не менялась.

Для оценки ощущения в HubScene: разгон/отпускание → разворот в воздухе →
деш/прыжок/вниз → деш/назад → деш/атака → двойной прыжок →
сход с края → проход сквозь платформу. Повторить с клавиатурой и геймпадом,
а также с бонусами скорости. Субъективные параметры следует доводить по игровому тесту.
